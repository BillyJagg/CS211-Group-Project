CS211 Group Project - 2048 and Luhn Validation 
  Project Overviews:
    This repository contains two separate programs written in C++ 17 for our CS211 Introduction to Programming group project.

  Part A: 2048 Game
    A console-based version of the 2048 game using a 5x5 integer array. Players move tiles up, down, left, or right and combine matching values to reach 2048.

  Planned features include:
  - four directional movement functions
  - tile merging and score tracking
  - random tile generation
  - win and game-over detection
  - saving and laoding game progress

  Part B: Luhn Validation
    A console program that validates 16-digit numbers using the Luhn checksum algorithm.

  Planned features include:
  - input validation
  - luhn checksum calculation
  - clear pass/ fair results
  - ability to check multiple numbers
