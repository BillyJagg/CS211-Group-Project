2048 Game:

    2048 is a console-based implementation of the classic 2048 puzzle game using a 5×5 board. Players move tiles in four directions to combine matching values, increase their score, and attempt to reach a tile value of 2048 or greater. The program includes scoring, move tracking, win and game-over detection, and the ability to save and load game progress from a text file.

Luhn Checksum Validator:

    Luhn Checksum Validator is a console program that verifies whether a 16-digit number satisfies the Luhn checksum algorithm. The program validates input format, preserves leading zeros, calculates the checksum, and reports whether the number passes or fails validation. Users can test multiple numbers during a single execution before exiting the program
